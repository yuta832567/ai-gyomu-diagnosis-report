# 環境変数の設定ガイド

本プロジェクトでは、診断結果の保存と共有機能のために Supabase を使用しています。ローカル開発環境でこれらの機能を有効にするには、以下の設定が必要です。

## 設定手順

1. プロジェクトルートにある `.env.example` をコピーして `.env.local` を作成します。
2. Supabase プロジェクトのダッシュボードにアクセスします。
3. **Project Settings > API** に移動します。
4. 以下の値をコピーして `.env.local` に貼り付けます。
   - `Project URL` → `NEXT_PUBLIC_SUPABASE_URL`
   - `anon public API key` → `NEXT_PUBLIC_SUPABASE_ANON_KEY`

## 環境変数一覧

| 変数名 | 説明 | 必須 |
| :--- | :--- | :--- |
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase プロジェクトの API URL | はい |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase の公開用 API キー | はい |

## 注意事項

- `.env.local` は Git の管理対象外（`.gitignore` に設定済み）です。機密情報をコミットしないよう注意してください。
- 環境変数が設定されていない場合、診断結果はブラウザの `localStorage` にのみ保存され、共有機能（URLによるアクセス）は利用できません。
