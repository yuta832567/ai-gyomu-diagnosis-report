# 環境変数の設定ガイド

本プロジェクトでは、診断結果の保存、共有、管理者機能、および AI アドバイス生成のために以下の環境変数を使用しています。

## 設定手順

1. プロジェクトルートにある `.env.example` をコピーして `.env.local` を作成します。
2. 以下の各サービスからキーを取得し、`.env.local` に設定してください。

### Supabase
1. Supabase プロジェクトのダッシュボードにアクセス。
2. **Project Settings > API** に移動。
3. `Project URL` と `anon public API key` をコピー。

### OpenAI
1. [OpenAI API Dashboard](https://platform.openai.com/api-keys) にアクセス。
2. 新しい Secret Key を作成してコピー。

### 管理画面パスワード
1. 管理画面（/admin）にログインするための任意のパスワードを自分で決めて設定します。

## 環境変数一覧

| 変数名 | 説明 | 必須 | 備考 |
| :--- | :--- | :--- | :--- |
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase プロジェクトの API URL | はい | クライアント側でも使用 |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase の公開用 API キー | はい | クライアント側でも使用 |
| `OPENAI_API_KEY` | OpenAI API キー | はい | **サーバーサイドのみで使用** |
| `NEXT_PUBLIC_ADMIN_PASSWORD` | 管理画面ログイン用パスワード | はい | |

## 注意事項

- `.env.local` は Git の管理対象外（`.gitignore` に設定済み）です。機密情報をコミットしないよう注意してください。
- `OPENAI_API_KEY` は絶対に `NEXT_PUBLIC_` プリフィックスを付けないでください。ブラウザ側に公開されると不正利用のリスクがあります。
- 環境変数が設定されていない場合の動作：
    - Supabase 未設定：共有機能が利用できません。
    - OpenAI 未設定：AI による追加アドバイスが生成されません（基本診断は動作します）。
    - 管理画面パスワード未設定：管理画面にログインできません。
