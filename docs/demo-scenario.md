## 2. 管理画面での確認ポイント (/admin)

ログイン後、以下の操作を行うことで組織全体の分析デモが可能です。

- **KPI集計**:
  - 登録された 3 つのシナリオが合算され、総削減時間（月間・年間）が大きく表示されていることを示す。
- **フィルター機能**:
  - 「会社名」で「デモ・セールス」を検索し、特定の部門の結果に絞り込む様子を見せる。
  - 「AIツール」で「Gemini」を選択し、特定のツール利用者のみの傾向を把握する。
- **詳細確認**:
  - 一覧から特定の診断結果の「外部リンクボタン」を押し、実際のレポート画面へ遷移する導線を見せる。

## 3. CSV出力・外部連携デモ

- **CSVダウンロード**:
  - フィルターされた状態で「CSVをダウンロード」をクリックし、Excel で開く。
  - 氏名、削減時間、共有URLなどが整理された状態で出力されることを確認する。
  - 「このデータを BI ツールや報告資料にそのまま活用できる」点を強調する。

## 4. デモ時の注意点

- **秘密情報の取り扱い**: 実際の顧客名やプロジェクト名は入力せず、必ず上記のようなデモ用データを使用してください。
- **AIの特性説明**: レポート下部の注意事項を見せながら、「AIは万能ではなく、最終的には人間が確認する必要がある」というガバナンスの視点を補足してください。
